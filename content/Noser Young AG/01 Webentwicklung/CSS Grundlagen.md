# CSS

CSS steht für **Cascading Style Sheets**. Es wird meistens zusammen mit HTML benutzt, kann aber auch mit XML verwendet werden.

> **Merksatz:** HTML ist das Haus, und CSS ist die Einrichtung des Hauses.

## Qualität prüfen
Der **W3C Markup Validation Service** dient dazu, zu überprüfen, ob die eigene Webseite Errors oder andere Fehler aufweist (siehe auch [[Wie das Web funktioniert]] → W3C-Konformität).
